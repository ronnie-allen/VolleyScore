# **App Name**: VolleyTracker

## Core Features:

- Team Management: Add and manage multiple volleyball teams with names and team members.
- Score Tracking: Track match scores and game progress for each team on a daily basis.
- Scoreboard Display: Display scoreboard information in a clean, game-themed user interface.

## Style Guidelines:

- Primary color: Dark green (#0d1321) to evoke a sense of the court.
- Secondary color: Light beige (#3c6e71) to provide contrast and readability.
- Accent: Orange (#d9d9d9) for interactive elements and highlights.
- Use volleyball-themed icons for teams and match-related actions.
- Clean, organized layout with clear sections for team management and score tracking.
- Subtle animations for score updates and transitions.
